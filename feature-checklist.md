# Spaniel Dog Feature Checklist

## Reference Photo Analysis (reference-dog-2.jpg)

### Head Features
- [ ] **Skull shape**: Rounded dome, not too wide
- [ ] **Snout**: Long, tapered muzzle (40% of head length)
- [ ] **Nose**: Small sphere at end of snout
- [ ] **Eyes**: Two small spheres, positioned on sides of head
- [ ] **Eyebrows**: Slight bulge above eyes (tan markings in photo)
- [ ] **Mouth line**: Subtle indication below snout

### Ear Features (CRITICAL - Signature Spaniel)
- [ ] **Length**: Very long, reaching to shoulder/chest level
- [ ] **Width**: Wide at top (4-5mm), tapering to 2mm at bottom
- [ ] **Texture**: Wavy/flowing appearance (multiple hull segments)
- [ ] **Position**: Set low on head, hanging down
- [ ] **Thickness**: Fuller at top, thinner at bottom
- [ ] **Curve**: Slight forward curve, not straight down

### Body Features
- [ ] **Chest**: Full, prominent, forward-projecting
- [ ] **Shoulders**: Defined transition from chest to body
- [ ] **Back**: Slight downward slope from shoulders to hips
- [ ] **Hips**: Narrower than chest, sitting position
- [ ] **Belly**: Tucked, not sagging
- [ ] **Overall proportion**: Body length ~2x head length

### Leg Features
- [ ] **Front legs**: Straight, upright, sturdy (6mm diameter)
- [ ] **Front paws**: Slightly wider at bottom
- [ ] **Back legs**: Tucked under body (sitting)
- [ ] **Back paws**: Visible from side, horizontal position
- [ ] **Leg spacing**: Wide enough for stability (~18-20mm apart)
- [ ] **Leg length**: Front legs taller than back (sitting pose)

### Tail Features
- [ ] **Position**: Low, at hip level
- [ ] **Length**: Short to medium (8-10mm)
- [ ] **Thickness**: Tapers from 4mm to 2mm
- [ ] **Curve**: Slight upward curve
- [ ] **Texture**: Smooth, not bushy

### Neck Features
- [ ] **Definition**: Clear separation between head and body
- [ ] **Length**: Medium length (not too short/long)
- [ ] **Thickness**: Thinner than chest, thicker than head
- [ ] **Angle**: Slight forward tilt

### Proportions (Critical)
- [ ] **Head-to-body ratio**: 1:3 (head is ~25% of total height)
- [ ] **Ear-to-head ratio**: Ears are 1.5-2x head height
- [ ] **Leg-to-body ratio**: Front legs ~60% of total height
- [ ] **Width-to-length ratio**: Width ~50% of length

### Pose & Stance
- [ ] **Sitting position**: Upright, alert posture
- [ ] **Weight distribution**: Centered over back legs
- [ ] **Head position**: Upright, looking forward
- [ ] **Chest forward**: Proud stance
- [ ] **Balance**: Stable on 4 contact points (2 front paws, 2 back paws)

### Overall Quality
- [ ] **Recognizable as spaniel**: Long ears are key identifier
- [ ] **Printable**: No overhangs >45°, all features ≥2mm
- [ ] **Manifold**: Clean geometry, no errors
- [ ] **Detailed**: Not too simple/abstract
- [ ] **Proportional**: Matches reference photo ratios

## Scoring System
- **Critical features** (must have): Ears, body, legs, head, snout
- **Important features** (should have): Neck, tail, eyes, proportions
- **Nice-to-have features**: Eyebrows, paws, texture details

**Target Score**: 35/40 features (87.5%)
